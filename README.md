# 🔮 ربات پیام ناشناس تلگرام

یک ربات تلگرام که به کاربران اجازه می‌دهد پیام‌های ناشناس ارسال کنند.

## امکانات

- 📩 ارسال پیام متنی ناشناس
- 📷 ارسال عکس
- 🎥 ارسال ویدیو
- 📎 ارسال فایل
- 🎤 ارسال صدا
- 😀 ارسال استیکر

## نصب و راه‌اندازی

1. کلون کنید:
```bash
git clone https://github.com/YOUR_USERNAME/anonymous-bot.git
cd anonymous-bot
```

2. پکیج‌ها رو نصب کنید:
```bash
pip install -r requirements.txt
```

3. فایل `.env` رو با مقادیر خودتون پر کنید:
```
BOT_TOKEN=your_bot_token
OWNER_CHAT_ID=your_chat_id
```

4. ربات رو اجرا کنید:
```bash
python anonymous_bot.py
```

## نحوه استفاده

1. ربات رو استارت کنید
2. پیام، عکس، ویدیو یا فایل بفرستید
3. مدیر ربات همه چیز رو می‌بینه ولی هویت شما مخفی می‌ماند
